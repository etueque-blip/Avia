# Carrier Strike ✈

Воздушные бои над океаном: взлёт с авианосца, ракеты разных типов, острова-города, пилотаж (петли и бочки), уровни пилота и спецмодули.

**Играть:** https://etueque-blip.github.io/Avia/

Игра — один файл `index.html` (three.js). Можно просто открыть его в браузере.

## Как приложение на экране «Домой»
- **iPhone / iPad (Safari):** откройте ссылку → кнопка «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».

Игра откроется на весь экран и будет работать без интернета после первого запуска.

## Острова
5 островов-баз, на каждом взлётная полоса:
- **2 штаба** (синих и красных) — там появляются игроки своей стороны;
- **2 острова обороны** — по одному у каждой стороны;
- **центральный остров** — нейтральный, достаётся тому, кто первым захватит.

С любого своего острова можно вылететь (ангар → «ВЫЛЕТ С») и сесть на его полосу для перезарядки.
Чтобы забрать вражеский остров: разбейте базу до 0% (бомбы, ракеты, пушка), потом летайте в кольце ниже 700 м.
**Кто захватит все 5 островов — тот победил.**

## Управление (клавиатура и мышь)
- Мышь — прицел (самолёт летит туда, куда вы смотрите), ЛКМ — пушка, ПКМ — ракета
- W/S — нос вниз/вверх, A/D — крен (бочка), Q/E — рыскание
- ← / → — ровный поворот без переворота (на телефоне кнопки ◀ ▶)
- Shift / Z или колесо — газ, X — форсаж, Y — турбо
- 1–5, R — выбор оружия, G — ловушки
- N — мёртвая петля, J — бочка
- U — ракетный удар по вражеской базе (летящие на вас ракеты можно сбить из пушки)
- L — шасси, V — камера, C — зум, M — карта, H — подсказки, Esc — меню

На телефоне и планшете: тяга слева, перетаскивание по экрану — штурвал, кнопки — оружие.

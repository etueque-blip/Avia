# Carrier Strike ✈

Воздушные бои над океаном: взлёт с авианосца, ракеты разных типов, острова-города, пилотаж (петли и бочки), уровни пилота и спецмодули.

**Играть:** https://etueque-blip.github.io/avia/

Игра — один файл `index.html` (three.js). Можно просто открыть его в браузере.

## Управление (клавиатура и мышь)
- Мышь — прицел (самолёт летит туда, куда вы смотрите), ЛКМ — пушка, ПКМ — ракета
- W/S — нос вниз/вверх, A/D — крен (бочка), Q/E — рыскание
- ← / → — ровный поворот без переворота (на телефоне кнопки ◀ ▶)
- Shift / Z или колесо — газ, X — форсаж, Y — турбо
- 1–5, R — выбор оружия, G — ловушки
- N — мёртвая петля, J — бочка
- L — шасси, V — камера, C — зум, M — карта, H — подсказки, Esc — меню

На телефоне и планшете: тяга слева, перетаскивание по экрану — штурвал, кнопки — оружие.
